# Support

## Questions and help

Read the [README](README.md), platform setup guides (`docs/setup-windows.md` and
`docs/setup-linux.md`), [development/testing guide](docs/development-testing.md), and
[troubleshooting guide](docs/troubleshooting/README.md) first.

For non-sensitive reproducible bugs, open an issue at
<https://github.com/jacksonsr451/freight-ecommerce-test/issues> using the bug report form. Use the
feature request form for proposed behavior. Do not put credentials, personal data, database dumps, or
unredacted logs in issues. See `SECURITY.md` for the current private vulnerability-reporting limitation.

## Support expectations

This repository has one maintainer recorded in Git history and no published support SLA. Support is
best-effort through public issues; response time, maintenance windows and compatibility outside the
documented Windows/Linux stack are not guaranteed. External provider questions require the provider's
own support channel and authorization.
